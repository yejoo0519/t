기본 설정

기준 GP 일괄 입력 (새 이벤트 시작)

한 줄에 닉네임 GP. 여기 넣은 GP가 출발선이 되고, 그 닉네임의 최근 인증·사용 GP는 0부터 다시 시작해요. 없는 닉네임은 새로 추가돼요.

상품 구성

등급상품명 (드래곤 이름이면 이미지 자동)총남음색

저장하면 상품 수량만큼 티켓이 만들어지고 섞여요. 수량 3개 이하인 상은 판 위쪽 큰 카드, 나머지는 가로줄로 나와요. 진행 중인 판에서 저장하면 판이 처음부터 다시 시작돼요 (길드원 사용 GP는 그대로).

길드원

닉네임기준최근 인증사용남음뽑기권비번

기준·최근 인증 칸을 고치고 칸 밖을 누르면 바로 저장돼요. 남음 = 최근 인증 − 기준 − 사용 (뽑기권으로 바뀐 GP는 사용에 포함). 뽑기권은 받았지만 아직 안 쓴 장수.

등급별 상품 (당첨 시 랜덤 지급)

당첨되면 이 등급의 상품 중 하나가 랜덤으로 지급돼요 (남은 코드가 많은 상품일수록 잘 나옴). 코드 칸에 한 줄에 하나씩 넣으면 하나씩 지급되고, 코드 개수가 곧 수량이에요. 코드를 비워두면 수량 제한 없이 "관리자 지급"으로 표시돼요. 판을 다시 섞어도 아이템과 남은 코드는 그대로예요.
